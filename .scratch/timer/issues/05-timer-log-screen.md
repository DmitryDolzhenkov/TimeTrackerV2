# View the Timer Log by date

Blocked by: 04

PRD: разделы 6, 7.

## Что делаем

Экран показывает хронологию Transition и Adjustment за выбранный день.

## Критерии приёмки

- [ ] Экран по умолчанию показывает текущий локальный день.
- [ ] Можно выбрать другую дату и увидеть её записи.
- [ ] Transition показывает время, старое и новое состояния и причину. Adjustment показывает время, количество минут и комментарий.
- [ ] Записи идут в хронологическом порядке, Transition и Adjustment в одном списке.
- [ ] Экран не позволяет редактировать или удалять записи.
- [ ] Записи старых дат не удаляются автоматически.
- [ ] Выборка записей по дню покрыта тестами. Работа экрана подтверждена ручной проверкой, результат описан в отчёте.
