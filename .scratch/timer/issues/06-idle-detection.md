# Detect inactivity and enter Idle

Blocked by: 01

PRD: разделы 4, 8, 9.

## Что делаем

Timer определяет отсутствие ввода через `GetLastInputInfo` и перестаёт считать время в Idle. Хуки и Raw Input не используются.

## Критерии приёмки

- [ ] Время последнего ввода опрашивается раз в 5–10 секунд через `GetLastInputInfo`. В коде нет `SetWindowsHookEx` и Raw Input, новых production-зависимостей нет.
- [ ] Вычисление времени без ввода корректно переживает переполнение 32-битного счётчика тиков.
- [ ] Без ввода дольше 15 минут Timer переходит Active → Idle. Порог задан константой и не настраивается в UI.
- [ ] Первые 15 минут входят в Counted Time, с момента перехода в Idle время не считается, а счётчик не уменьшается.
- [ ] При первом вводе Timer сам переходит Idle → Active, без подтверждения.
- [ ] В Stop отсутствие ввода не создаёт Transition.
- [ ] Выход из приложения и кнопка «Стоп» в Idle записывают Transition Idle → Stop.
- [ ] Логика покрыта тестами с управляемым временем и подменой источника ввода. Работа с настоящим `GetLastInputInfo` подтверждена ручной проверкой, результат описан в отчёте.
