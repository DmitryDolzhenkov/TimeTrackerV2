# Split the Daily Session at local midnight

Blocked by: 01

PRD: раздел 5.

## Что делаем

Граница Daily Session проходит по локальной полуночи, при этом работающий Timer не останавливается.

## Критерии приёмки

- [ ] Интервал Active через полночь делится между двумя локальными календарными днями.
- [ ] После полуночи счётчик в окне начинается с нуля без перезапуска приложения. Timer остаётся в Active, новая Transition не создаётся.
- [ ] Локальный день определяется по смещению, записанному в каждой записи Timer Log.
- [ ] Переход на летнее и зимнее время не меняет Counted Time.
- [ ] Покрыто тестами с управляемым временем: полночь, перевод времени и запись, сделанная в другом часовом поясе.
