# Package a self-contained zip and document it

Blocked by: 09

PRD: разделы 8, 9.

## Что делаем

Готовим сборку для запуска на компьютере без установленного .NET и описываем, как с ней работать.

## Критерии приёмки

- [ ] Одна команда собирает zip с self-contained сборкой для Windows, без упаковки в один файл и без обфускации.
- [ ] Приложение из zip запускается на компьютере или в чистой среде без установленного .NET, результат описан в отчёте. Если такой среды нет, это указывается как непроверенный критерий.
- [ ] README описывает сборку, тесты, локальный запуск и расположение данных.
- [ ] README описывает предупреждение SmartScreen и ограничения из раздела 9 PRD.
- [ ] Заключительный прогон сборки и всех тестов успешен.
