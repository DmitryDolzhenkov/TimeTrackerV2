# Run from the tray as a single instance

Blocked by: 01

PRD: разделы 4, 7.

## Что делаем

Приложение работает из трея, поэтому закрытие окна не останавливает учёт, и запускается только один его экземпляр.

## Критерии приёмки

- [ ] Приложение показывает иконку в трее, которая открывает окно.
- [ ] Закрытие окна сворачивает приложение в трей, Timer State не меняется.
- [ ] Пункт «Выход» в меню трея завершает приложение. Из Active перед завершением записывается Transition в Stop.
- [ ] Выход из Stop не создаёт Transition.
- [ ] Повторный запуск не создаёт второй работающий экземпляр, а открывает окно уже работающего.
- [ ] Логика выхода покрыта тестами. Поведение трея и второго экземпляра подтверждено ручной проверкой, результат описан в отчёте.

## Вне тикета

Закрытие окна при завершении Windows (тикет 08).
