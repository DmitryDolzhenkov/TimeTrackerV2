# Record Shutdown on Windows session end

Blocked by: 02, 07

PRD: раздел 4, подраздел Shutdown.

## Что делаем

Штатное завершение Windows и выход из учётной записи записываются как Shutdown и не мешают Windows завершить работу.

## Критерии приёмки

- [ ] Shutdown записывается из Active, Idle и Lock, только когда завершение окончательно (`SessionEnded`).
- [ ] Запрос на завершение, который затем отменён, не меняет Timer State и не создаёт записей.
- [ ] Причина различает выключение и выход из учётной записи (`logoff`).
- [ ] В Stop завершение Windows не создаёт Transition.
- [ ] При завершении Windows закрытие окна не сворачивает приложение в трей и не задерживает завершение.
- [ ] Новый запуск после Shutdown записывает Transition Shutdown → Stop с причиной `startup`, а Daily Session того же дня сохраняется.
- [ ] Логика покрыта тестами с подменой адаптера. Выключение, отменённое выключение и выход из учётной записи подтверждены ручной проверкой, результат описан в отчёте.
