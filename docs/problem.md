# TimeTracker — problem statement

 Необходимо написать приложение для трекинга времени. 
- Это должен быть простой таймер без разделения на проекты, задачи или 
категории. Пользователь просто запускает таймер, и он начинает считать время. 
- У таймера должно быть несколько состояний: 
- stop — стандартное состояние при запуске приложения; 
- active — таймер запущен; 
- idle — пользователь неактивен более 15 минут; 
- lock — пользователь заблокировал компьютер; 
- shutdown — пользователь выключил компьютер.

# 2. Scope
- Важно: приложение должно уметь определять период неактивности пользователя. 
Под неактивностью мы понимаем ситуацию, когда пользователь не печатает на 
клавиатуре и не двигает мышью более 15 минут. Нам интересно, как именно ты 
предложишь это отслеживать. 
- При переходе в состояния lock и shutdown таймер должен останавливаться. 
- Приложение должно показывать длительность текущей дневной сессии. 
- Также у пользователя должна быть возможность вручную добавлять или убавлять 
минуты. Например, если он забыл вовремя запустить таймер и хочет 
скорректировать время. 
- Мы, как пользователи, должны иметь возможность просматривать лог изменений 
состояний таймера. 
- доменную модель делаем универсальной, но решение приложение делаем для windows
- используем библиотеки , которые не выглядят как снифер и чувствительный для антивирусов подозрительной активностью
